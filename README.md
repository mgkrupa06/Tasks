 Library Management System (Java)
This is a simple Library Management System built in Java.
It demonstrates object-oriented programming (OOP) concepts, including classes, interfaces, exception handling, and unit testing.

 Features
Add books with a title, author, and unique book code.
Issue a book (mark it as borrowed).
Return a book (mark it as available).
Check if a book is available.
Custom exception handling for missing books.
Unit testing with JUnit 5.
